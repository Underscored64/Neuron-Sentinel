# Neuron Sentinel

A small flood risk prediction app for the cantons of Lomé, built from weather data and a local vulnerability index.

The project brings together:
- rainfall and humidity observations,
- a canton-level FRI risk score,
- a machine learning model to estimate flood probability over a 6-hour window,
- a FastAPI service to expose the model in a simple and usable way.

## Context

The goal is straightforward: provide a quick estimate of flood risk based on locally observed weather conditions. The model does not replace a full hydrological assessment, but it can still be useful as a decision-support tool for rapid monitoring or operational dashboards.

The repository also includes data preparation scripts and the training pipeline, so the project remains reproducible and easy to understand.

## What the project does

- reads historical weather data for the cantons of Lomé,
- computes useful indicators such as 1h and 6h rainfall,
- enriches the dataset with the FRI (Flood Risk Index) for each canton,
- trains a classification model with labels `low`, `medium`, and `high`,
- exposes the result through a REST API.

## Run the API locally

```bash
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

Then open:

```text
http://localhost:8000/docs
```

The Swagger documentation generated by FastAPI makes it easy to test the endpoints directly in the browser.

## Main endpoint

### POST /predict

Used to request a prediction for a given canton.

Example:

```bash
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "zone_id": "Baguida",
    "rainfall_1h": 12.5,
    "rainfall_6h": 48.0,
    "humidity": 78
  }'
```

Expected response:

```json
{
  "zone_id": "Baguida",
  "flood_probability": 0.82,
  "risk_level": "HIGH",
  "prediction_horizon": "6h"
}
```

The `zone_id` value corresponds to the canton name, as listed in the geospatial data.

## Data

The project is based on two main data sources:

1. a geospatial file containing the cantons of Lomé and their FRI,
2. historical weather observations retrieved from the Open-Meteo API.

The processed datasets are stored in `data/processed/`.

## Model training

To rerun the full training pipeline:

```bash
python src/model_training.py
```

The script:
- loads the reference dataset,
- merges FRI information,
- builds features such as rainfall over 6 hours,
- trains the model,
- saves the trained model and label mapping in `models/`.

## Deployment

- `Procfile`
- `nixpacks.toml`

The service starts with:

```bash
uvicorn api.main:app --host 0.0.0.0 --port $PORT
```

## Current limitations

- the model is tailored to the Lomé context and depends directly on the available data,
- predictions are estimates based on weather and geographic signals,
- model quality depends on data reliability and the associated FRI values.
